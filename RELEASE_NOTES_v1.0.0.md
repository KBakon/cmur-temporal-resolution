# v1.0.0 — Initial reproducibility release

This version contains archived Eurostat statistical and structural source inputs, author-generated provenance and analysis datasets, the analysis and verification scripts, and reproducible figure/table assets for the EU Circular Material Use Rate temporal-resolution study. The package was tested from a clean extracted copy: source integrity, provenance reconstruction, temporal analysis, headline checks and asset regeneration completed successfully.

Recommended Git tag: `v1.0.0`.

The source catalog records acquisition dates, exact URLs and rights treatment.
