# v1.1.0 — Expanded frozen reproducibility release

This release updates the public CMUR temporal-resolution reproducibility package to science version `CMUR-TEMPORAL-AUDIT-P2-2026-11-11`.

Compared with v1.0.0, it adds the frozen P1A temporal-support diagnostics and P1C calibration/robustness diagnostics, expanded verification outputs, the submission-stage manuscript source sections and bibliography, and supplementary Tables S1–S5 with their supporting assets.

The archived Eurostat statistical source inputs remain the frozen source basis of the analysis. The release also contains the final frozen processed provenance and analysis tables, production and verification scripts, figures and table assets, source catalog, licensing information, and SHA-256 integrity metadata.

The release does not claim to reconstruct same-vintage CMUR from components or identify the true intervening-year error distribution.
